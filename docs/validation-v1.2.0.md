# v1.2.0 验证摘要

本页摘录 2026-10-05 的版本验收数值，不包含原始切片、派生预览、私有机器路径或运行环境。本版本的两份真实 KFBF 实样通过 OME-TIFF 转换、完整像素比较与 **QuPath 0.6.0 实际无界面读取**；未执行桌面 GUI 验收。

每通道存在未记录区域：四通道实样为 4,289,600 像素（0.96081%），六通道实样为 9,338,880 像素（0.64400%）。此次按明确选择显示为黑色，并保存完整坐标清单、逐通道计数和填充值验证。**未知空缺不代表阴性表达，定量分析应排除这些位置。** 新切片仍默认遇到缺失便停止。

两份输出的全部已记录基础层像素保持一致；通道名称、次序、显示颜色和可读取的物理像素尺寸已核对。显示金字塔重新生成，源厂商低分辨率层、关联小型 JPEG 及专有字段仍留在原文件与审计记录中。曝光字段只保留原始数值，单位未知，未编造 OME 定量曝光时间。无损输出不能逆转源 JPEG 已有压缩损失。

## 覆盖与边界

- 本次发布验收记录包含 134 项单元检查、1／3／6／8 通道合成 KFBF 实际转换、通用流程与明场 KFB 回归；均通过。复现入口见 [测试方法](testing.md)。
- KFBF 通道数按源文件读取，目前解析上限为 32；真实厂商样本已验证 4／6 通道，上限不代表 32 通道实样已验证。
- 真实 KFBF 结论限于上述 2.1 灰度 JPEG8 布局与 QuPath 0.6.0。KFBF 16 位、其他编码、Z/T 堆栈及未知布局明确停止。通用独立通道 uint16 支持保持不变。
- QuPath 验证检查元数据、各通道、层级和多个源 ROI；不是由 QuPath 逐像素读遍整片。完整像素比较由转换流程的独立校验阶段完成。
- 通用大型 WSI 源／目标校验使用抽样；KFB 比较保留的原生层全部像素；KFBF 比较已记录基础层和所有输出层。不能把一种分支的校验范围推广到所有输入。
- 尚无 Agent 有／无 Skill 的独立效果对照，未给出触发准确率或效率提升数值。其他厂商样本、更多 Linux 发行版与其他 QuPath 版本仍需实测。
